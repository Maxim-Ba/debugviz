DebugViz

Статический граф Go-кода + live trace в одном 3D UI. Entry points (HTTP, gRPC, CLI, worker) привязаны к функциям — видно, какой путь выполнился внутри binary.

Открыть 3D UI GitHub Quick Start 
git clone https://github.com/Maxim-Ba/debugviz.git
cd debugviz
docker compose up

# UI :3000 · server :4000 · demo/http :8080
curl http://localhost:8080/api/users/1

Static graph

debugviz scan строит packages, calls и entry points из исходников.

Live path

Runtime spans мапятся на узлы графа и подсвечиваются в реальном времени.

Codegen

debugviz instrument добавляет inner spans без ручной разметки.

Auto wire

debugviz wire подключает middleware и exporter одной командой (M6).

Для portfolio / demo

Запишите 60-секундный screencast: docker compose up → UI → curl → подсветка path. Ссылка на UI и README — в описании репозитория.
